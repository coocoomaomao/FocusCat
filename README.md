# FocusCat 墨团专注屋 🐈‍⬛

> 你专注，猫生活。

FocusCat 是喵造实验室的桌面专注陪伴工具。它不是给番茄钟套一层猫皮，而是把你的专注时间变成墨团的生活、收藏和小房间成长。

## v0.1 MVP

- 25 分钟 / 50 分钟专注
- 5 分钟休息
- 墨团实时状态：趴着、专注、暂停盯人、完成庆祝
- 完成专注后随机带回礼物
- 普通 / 稀有 / SSR 三档收藏
- 8 件首发收藏物
- 今日分钟、累计分钟、完成次数、连续天数、鱼干币
- 收藏品展示到房间小架子
- 数据全部保存在本机
- 支持窗口置顶陪伴

## 爆款演示点

第一条视频可以直接拍：

> 为了让我别摸鱼，我做了一只会监督我工作的黑猫。

画面流程：开始 25 分钟 → 墨团趴下 → 暂停时抬头盯你 → 完成后跳起来 → 抽到 SSR 礼物。
